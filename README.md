### What I learned

I practiced using CSS custom properties (variables) to maintain a consistent color palette as defined by the design system. Additionally, I utilized Flexbox to properly center the component vertically and horizontally on the viewport.

```css
body {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}
```
